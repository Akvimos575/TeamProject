# MoonSweeperBot — автоигрок для Moon Sweepers

Программа сама играет в **Moon Sweepers** на вашем ПК:

- находит ближайший к базе неочищенный сектор-шестиугольник и чистит его «змейкой» (длинными параллельными полосами — так советуют гайды);
- после этого идёт к следующему сектору **по кругу влево** и обходит базу кольцами, расширяя расчищенную область спиралью;
- когда контейнер инструмента заполнен, идёт к базе, сгружает пыль в **упаковщик** (он сам её продаёт) и возвращается к работе;
- на базе покупает улучшения по вашему **списку приоритетов**.

Бот не читает память игры и ничего в неё не внедряет. Он смотрит на экран (снимки + встроенное распознавание текста Windows) и нажимает клавиши и мышь, как живой игрок.

## Как бот ориентируется

| Что нужно знать | Откуда бот это берёт |
|---|---|
| В каком я секторе и насколько он чист | Номер сектора и % в правом верхнем углу (OCR) |
| Где граница сектора | Номер сектора в HUD сменился — значит, граница пересечена |
| Где база | Цветная метка базы на шкале-компасе вверху экрана |
| Куда я смотрю | Повороты мышью на точно рассчитанное число отсчётов |
| Застрял ли я | Картинка в центре экрана перестала меняться при ходьбе |

**Спираль.** Кольцо 0 — сектор базы. Дальше бот делает шаг наружу (спиной к базе) и идёт по касательной, держа базу сбоку. При каждой смене сектора он проверяет процент очистки: грязный сектор чистит, чистый проходит без остановки. Кольцо считается пройденным, когда бот снова приходит в первый сектор кольца (в кольце *k* около 6·*k* секторов). Затем шаг наружу и следующее кольцо. Поэтому бот всегда сначала дочищает ближайшие к базе сектора.

> «Влево» — с точки зрения персонажа, который стоит лицом **от базы**: база остаётся у него слева. Если нужно наоборот, поставьте в `config.json` `"CircleDirection": "Right"`.

## Требования

- Windows 10 (версия 2004 и новее) или Windows 11.
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0). Если у вас Visual Studio 2022, он обычно уже установлен.
- Языковой пакет **English** в Windows (Параметры → Время и язык → Язык). Он нужен встроенному OCR; другой установленный язык можно указать в `OcrLanguage`.
- Игра в режиме **«окно без рамки» (Borderless) или в окне**. В эксклюзивном полноэкранном режиме снимки экрана могут получаться чёрными.
- Если игра запущена от имени администратора, бота тоже нужно запускать от имени администратора: иначе Windows не пропустит нажатия клавиш.

## Сборка

Откройте `TeamProject.sln` в Visual Studio 2022 и соберите проект (Release). Либо соберите из консоли:

```bash
dotnet build TeamProject/TeamProject.csproj -c Release
```

Программа появится в `TeamProject\bin\Release\net8.0-windows10.0.19041.0\MoonSweeperBot.exe`. Рядом лежит `config.json`, туда же сохраняются `calibration.json`, `botstate.json` и `bot.log`.

Если запустить `MoonSweeperBot.exe` без параметров, он покажет меню команд.

## Первая настройка (один раз)

### 1. Калибровка экрана

```bash
MoonSweeperBot calibrate
```

Переключитесь в игру. Наводите курсор на указанные места и нажимайте **F6** (**F7** — пропустить шаг). Бот спросит:

1. углы области с **номером сектора**;
2. углы области с **процентом очистки** (F7, если процент в той же области);
3. углы всей **шкалы-компаса** вверху экрана и её **центр**;
4. **цвет метки базы** — наведите точно на метку;
5. область **денег** (без неё бот не сможет покупать);
6. **шкалу заполнения** контейнера и её цвет (F7 — разгружаться по таймеру);
7. область **подсказки** «Load packager» — для этого шага подойдите к упаковщику.

Совет: чтобы курсор был свободен, а HUD оставался на экране, откройте меню паузы (Escape).

Снимки всех областей сохраняются в папку `debug\`. Проверьте, что текст в них виден целиком.

### 2. Калибровка поворота

Встаньте так, чтобы метка базы была на шкале, и выполните:

```bash
MoonSweeperBot calibrate-turn
```

Бот сам сделает полный оборот и вычислит, сколько отсчётов мыши приходится на 1° и сколько градусов на 1 пиксель шкалы. Не трогайте мышь, пока идёт калибровка.

### 3. Проверка

```bash
MoonSweeperBot test-hud
```

Раз в полсекунды бот печатает, что он видит: сектор, %, угол на базу, заполнение контейнера, деньги, есть ли подсказка упаковщика и насколько меняется картинка. Поверните камеру: угол на базу должен меняться плавно, а при взгляде прямо на базу быть около 0°. Выход — F9.

Если OCR ошибается, попробуйте в `config.json` `OcrScale` 4–5 или `OcrThreshold` 140–180, и чуть шире или уже выделите область.

### 4. Макросы покупок (по желанию)

Для каждого улучшения из списка в `config.json` запишите, как вы его покупаете:

```bash
MoonSweeperBot record-macro broom_container
```

Через 3 секунды начнётся запись: откройте меню, купите улучшение, закройте меню и нажмите **F12**. Затем в `config.json` проверьте у этого пункта цену (`Cost`), путь к макросу (`Macro`) и включите его (`"Enabled": true`). Проверить макрос можно так:

```bash
MoonSweeperBot play-macro broom_container
```

Бот покупает пункты строго по порядку списка: пока не хватает денег на верхний невыполненный пункт, он копит. Порядок по умолчанию взят из гайдов: сначала вместимость инструмента и новый инструмент, затем экономика (Market Contracts → Section Bonus → Supplier Network → Moon Exchange), дорогая автоматизация (J.O.O.N.A.S.) в конце. Для нового инструмента укажите `LaneWidthMs` (ширину полосы) и `SelectToolKey` (клавишу слота).

## Запуск

1. Поставьте персонажа **у базы, рядом с упаковщиком** (при первом запуске сектор, где стоит персонаж, запоминается как сектор базы).
2. Возьмите в руки инструмент для чистки.
3. Выполните команду ниже и за 5 секунд переключитесь в игру:

```bash
MoonSweeperBot run
```

| Клавиша | Действие |
|---|---|
| **F8** | пауза / продолжить (все клавиши отпускаются) |
| **F9** | остановить бота |
| **F10** | сохранить прогресс |

Прогресс (сектор базы, номер кольца, очищенные сектора, купленные улучшения) хранится в `botstate.json`. Если персонаж после перезапуска стоит там же, где бот остановился, обход продолжится с того же места. Иначе бот сам дойдёт до базы и начнёт спираль заново, а уже очищенные сектора пройдёт без остановки. Начать с нуля можно командой `MoonSweeperBot reset-state`.

## Важные настройки `config.json`

| Параметр | Что делает |
|---|---|
| `GameProcessName` | имя процесса игры; если указано, бот встаёт на паузу, когда игра не в фокусе |
| `PercentMeaning` | `Cleaned` (HUD показывает % очистки) или `DustRemaining` (% оставшейся пыли) |
| `CleanThresholdPercent` | с какого процента сектор считается очищенным (игра засчитывает при ≤1% пыли) |
| `CircleDirection` | `Left` / `Right` — направление обхода |
| `LaneWidthMs` | сколько миллисекунд идти вбок между полосами (подбирается под ширину щётки) |
| `Keys.SectorBordersMode` | `Toggle` — G включает границы один раз; `Scan` — G нажимается, когда номер сектора не виден |
| `Keys.LockBrush` | клавиша фиксации поворота щётки (в игре `L`), пусто — не нажимать |
| `UnloadMode` | `FillGauge` (по шкале контейнера), `Timer` (каждые `UnloadEveryMinutes`), `Never` |
| `PackagerPromptText` | часть текста подсказки у упаковщика, как она написана в вашей игре |
| `Upgrades` | список покупок по приоритету |

## Ограничения

- Бот не видит 3D-мир. Камни и постройки он обходит только эвристикой «застрял → назад, поворот, прыжок».
- Упаковщик бот ищет рядом с точкой метки базы: поворачивается на месте и делает короткие вылазки в 8 направлениях. Ставьте упаковщик недалеко от метки.
- Все области и цвета привязаны к вашему разрешению и интерфейсу. После смены разрешения или обновления игры, которое меняет HUD, повторите калибровку. Макросы покупок тоже может понадобиться перезаписать.
- Используйте бота в одиночной игре или с согласия напарников в кооперативе.

## Структура проекта

```
TeamProject/
  Program.cs          команды (run, calibrate, test-hud, ...)
  Core/               чистая логика без WinAPI: разбор OCR, углы, спираль, конфиг, состояние
  Native/Win32.cs     SendInput, GetAsyncKeyState, работа с окнами
  Input/              эмуляция клавиатуры и мыши, горячие клавиши, пауза
  Vision/             снимки экрана, OCR Windows, HUD, шкала-компас, шкала заполнения, детектор застревания
  Navigation/         движение к базе, по кругу, наружу, обход препятствий
  Cleaning/           чистка сектора змейкой
  Economy/            разгрузка в упаковщик, покупки, макросы
  Setup/              калибровка и запись макросов
  Bot/BotRunner.cs    главный цикл
TeamProject.Tests/    тесты логики Core (xUnit, работают на любой ОС)
```

Запуск тестов:

```bash
dotnet test TeamProject.Tests
```
